## 📝 1. Опис Завдання

Проект реалізує динамічну структуру даних **Гістограма (Histogram)** з фіксованою кількістю стовпців ($M$) на заданому інтервалі $[\text{min\_hist}, \text{max\_hist}]$. Структура призначена для ефективного зберігання та статистичного аналізу великих обсягів даних без необхідності зберігати кожен окремий елемент.

### Ключові характеристики Гістограми:
* `min_hist`, `max_hist`: Межі інтервалу.
* `M`: Кількість рівномірних стовпців.
* `frequency[M]`: Масив частот (кількість елементів у кожному стовпці).

## ⚙️ 3. Спеціальні Методи та Алгоритми

Клас `Histogram` реалізує три варіанти додавання чисел, які виходять за межі інтервалу $[\text{min\_hist}, \text{max\_hist}]$, а також повний набір статистичних характеристик:

### Стратегії додавання даних:
1.  `addNumber_Ignore(double x)`: Числа поза межами **ігноруються**.
2.  `addNumber_ToExtremes(double x)`: Числа поза межами додаються до **крайніх стовпців** (першого або останнього).
3.  `addNumber_UpdateBounds(double x)`: Числа поза межами **змінюють** $\text{min\_hist}$ або $\text{max\_hist}$ (вимагає скидання існуючих частот).

### Методи Статистичного Аналізу (Javadoc доступний у `doc/`):
* `mean()`: Середнє значення (за центрами стовпців).
* `median()`: Медіана (з використанням лінійної інтерполяції для згрупованих даних).
* `variance()`: Дисперсія.
* `dev()`: Середнє відхилення (стандартне відхилення).
* `skewness()`: Коефіцієнт асиметрії.
* `kurtosis()`: Коефіцієнт ексцесу (надлишковий ексцес).
* `mode()`: Мода (центр стовпця з найбільшою частотою).
* `range()`: Діапазон.
* `meanAbsoluteDeviation()`: Середнє абсолютне відхилення.
* `coefficientOfVariation()`: Коефіцієнт варіації.
* `quartile1()`: Перший квартиль ($Q_1$).
